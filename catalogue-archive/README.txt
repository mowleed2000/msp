Old 123-item catalogue (kept for revert)
========================================
This is the catalogue that was live before the 209-image zip load.

Live site files (do not replace these unless reverting):
  catalogue-data.js     312 products — current
  catalogue.html
  catalogue.js

To revert the catalogue to the old 123 cards:
  1. Copy catalogue-archive/catalogue-data-123.js over catalogue-data.js
  2. Copy catalogue-archive/catalogue.html-123 over catalogue.html
     (optional — only needed if you also want the old sidebar counts)
  3. Commit and push the GitHub Pages branch:
     cursor/msp-site-from-itplanet-eb95

The old vape kit cards (Lost Mary 30K, Hayati, IVG, Velo, etc.) are
still in the live 312-item catalogue. This archive is only if you
want to drop the zip-loaded phones/accessories/salts entirely.
